# 【方向A】梗图改字器 - 设计文档

## 1. 产品定位转变

| 维度 | 原方案 | 新方案 |
|-------|--------|--------|
| 定位 | 图片编辑器（空白画布+贴纸+文字） | 梗图改字器（模板+改字+导出） |
| 起点 | 用户自己构思设计 | 现成梗图模板，改个字就行 |
| 门槛 | 高（需要美术和创意） | 低（不需要任何设计能力） |
| 成品质量 | 取决于用户水平 | 模板决定下限，保证每张都像样子 |
| 竞品对标 | PicsArt、美图秀秀 | 表情家园、闪萌表情 |

## 2. 核心用户故事

> 作为一个斗图达人，我想要在3秒内将一张经典梗图的文字改成我想说的话，然后直接发到群里，从而在斗图中保持优势。

## 3. 新用户流程（3步）

```
打开小程序
    ↓
浏览梗图模板库（首页）
    ↓
点击喜欢的模板
    ↓
进入编辑器（底图已定，只需改字）
    ↓
导出并分享到微信
```

## 4. 功能切割

### 4.1 首页（模板库）
- 模板展示：二列格子流式布局，每个模板显示预览图+模板名
- 分类标签：全部、热门、打工人、恋爱、懒狐、虚拱、可爱、摸鱼
- 搜索：关键词搜索模板
- 上拉加载更多

### 4.2 编辑器（改字模式）
- 底图固定：不可更改（模板图片就是底图）
- 文字编辑：点击模板上的文字位置，直接输入新文字
- 文字样式：大小、颜色、粗细、描边、阴影
- 文字位置：可拖拽调整（保留微调能力）
- 一键恢复原文：方便对比
- 导出：保存到相册

### 4.3 进阶（保留自由编辑）
- 首页增加"自由创作"入口，保留原有的空白画布编辑器
- 满足高级用户自由发挥的需求

## 5. 模板素材方案

由于实时爬虫受限于版权，采用以下混合方案：

1. **代码生成原创模板**（50+个）
   - 熊猫头系列（带不同表情）
   - 蘑菇头系列
   - 杀马特系列
   - 简约卡通人物（带对话泡）
   - 经典梗图底图（纯色+对话框）

2. **内置热门文案**
   - 每个模板配合适的默认文案，用户可直接修改
   - 文案分类：打工人、恋爱、懒狐、虚拱、干饭

## 6. 数据模型

```js
// 模板
{
  id: 'tmpl_001',
  name: '熊猫头无语',
  category: 'hot',        // hot/work/love/roast/cute/food
  src: '/assets/templates/panda_speechless.png',
  defaultText: '无语了家人们',
  textPosition: { x: 128, y: 200 },  // 文字中心点（相对于模板图片）
  textStyle: {
    fontSize: 24,
    color: '#000000',
    strokeColor: '#FFFFFF',
    strokeWidth: 2,
    maxWidth: 200
  },
  tag: '热门'
}
```
