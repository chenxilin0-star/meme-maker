# 【方向B】表情包大全 - 设计文档

## 1. 产品定位转变

| 维度 | 方向A（改字器） | 方向B（表情包大全） |
|-------|------------------|----------------------|
| 定位 | 模板改字生成工具 | 表情包搜索/浏览/收藏库 |
| 起点 | 用户主动创作 | 用户被动消费现成内容 |
| 门槛 | 低（改个字就行） | 极低（点一下就发） |
| 竞品对标 | 表情家园、闪萌表情 | 表情家园、闪萌表情、搜狗表情 |
| 核心价值 | 创作自己的表情 | 快速找到想要的表情 |
| 变现潜力 | 低（工具类难变现） | 中（广告+会员去广告） |

## 2. 核心用户故事

> 作为一个斗图达人，当我想发一个特定场景的表情时，希望能在2秒内搜到合适的表情包并直接发到微信，不用自己做。

## 3. 新用户流程（2步）

```
打开小程序
    ↓
浏览/搜索表情包
    ↓
点击发送到微信 / 保存到相册
```

## 4. 功能切割

### 4.1 首页（表情包流）
- 搜索栏：关键词搜索表情包（支持模糊匹配）
- 分类标签：全部、热门、打工人、恋爱、懒狐、虚拱、可爱、摸鱼、生气、搞笑
- 表情包列表：二列格子布局，点击展示大图
- 上拉加载更多
- 空状态提示

### 4.2 表情包详情
- 大图预览
- 一键发送到微信好友/群聊
- 保存到相册
- 收藏功能
- 关联推荐（同类别表情包）

### 4.3 收藏页
- 我的收藏列表
- 最近使用

### 4.4 原有功能保留
- 自由创作入口（空白画布编辑器）保留作为进阶功能
- 原有的模板改字功能也保留，作为"自定义表情"入口

## 5. 数据模型

```js
// 表情包
{
  id: 'meme_001',
  name: '熊猫头无语',
  category: 'hot',
  tags: ['熊猫头', '无语', '污霰', '经典'],
  src: '/assets/memes/meme_001.jpg',
  text: '无语了家人们',
  usage: 0,        // 使用次数
  createTime: '',
  isCollected: false
}
```

## 6. 素材获取方案

1. **当前已有素材**：19个原创绘制模板 + 1000张从 expression-pack 获取的表情包
2. **后续扩展**：继续爬取更多开源表情包资源 / 用户上传 / 运营人工录入

## 7. 验收标准

- [ ] 首页展示表情包列表，支持分类和搜索
- [ ] 点击表情包展示大图，支持保存和分享
- [ ] 收藏功能
- [ ] 自由创作入口保留
- [ ] 自定义表情（模板改字）入口保留

## 8. 与方向A的关系

方向B不是替代方向A，而是**叠加**：
- 主页面变为表情包大全（消费现成内容）
- 保留"自定义表情"入口（方向A的模板改字功能）
- 保留"自由创作"入口（原有的空白画布编辑器）
